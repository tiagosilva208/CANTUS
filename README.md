# CANTUS

A music editor and analysis tool featuring spectrogram visualization and MIDI manipulation, inspired by AnthemScore.

## About

CANTUS is an advanced music editing and analysis platform designed to provide musicians, composers, and music producers with powerful tools for audio visualization, transcription, and manipulation. Built with a focus on spectrogram-based editing similar to AnthemScore, CANTUS combines visual music analysis with comprehensive editing capabilities.

## Features (Planned)

### Core
- **Spectrogram Visualization**: Real-time spectrogram display of audio files
- **MIDI Import/Export**: Load and save MIDI files
- **Audio Playback**: Play and control audio with transport controls (play, pause, stop)

### Editing & Sections
- **Section Management**: Add, edit, merge, and split musical sections
- **Section Comparison**: Compare different sections for similarity
- **Repeat Detection**: Automatically find repeated sections in compositions

### MIDI Tools
- **Multi-Channel Support**: Manage multiple MIDI channels
- **Channel Organization**: List and organize MIDI channels
- **Piano Visualization**: Visual piano keyboard for reference

### Analysis & Tools
- **Audio Analysis**: Fourier analysis and spectral features
- **Overlay Tools**: Layer multiple audio/MIDI tracks
- **Note Mode**: Experimental note detection and transcription

## Tech Stack (In Progress)

- **GUI**: `tkinter`
- **Audio Processing**: `librosa`, `scipy`, `soundfile`
- **MIDI**: `mido`
- **Visualization**: `matplotlib`
- **Music Analysis**: `essentia` (planned)
